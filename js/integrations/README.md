# Integraciones (FASE 3)

- Todas las integraciones están **preparadas pero desactivadas por defecto**.
- No se activan automáticamente ni envían datos.
- Cualquier activación futura requiere autorización explícita, revisión de privacidad/seguridad y, si aplica, arquitectura cifrada.
- En v1 no existe sincronización entre dispositivos ni servicios externos para datos personales.
